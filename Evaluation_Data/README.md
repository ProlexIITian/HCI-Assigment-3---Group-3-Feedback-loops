# Evaluation_Data

Put the files exported from the app here after the sessions (Study → Export CSV + JSON):

- `tasks.csv` — one row per participant × task (outcome, seconds, taps, back presses, slips, recovered, SEQ, B5c dwell, screens, notes)
- `questionnaires.csv` — one row per participant × prototype (10 SUS items, SUS score, comfort, trust-symbol comprehension)
- `participants.csv` — anonymised profile, order, preference, seller answers
- `study_raw.json` — everything above plus the event log

The `*_TEMPLATE.csv` files only show the column layout. Delete them once real data is in. Do not add names, phone numbers, photos or audio.
