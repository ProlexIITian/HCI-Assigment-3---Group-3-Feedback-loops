# Compromises in prototyping

We built **one horizontal layer across everything** and **two vertical slices to full depth**, and faked (clearly) only what a browser cannot do.

## Horizontal (breadth)

| Area | In the prototype | Compromise |
|---|---|---|
| Act families | all 10 families reachable from Home | 31 acts instead of the 90 in A1 (2–6 per family) |
| Languages | Marathi, Hindi, Gujarati, English for all 31 acts × 3 registers; Bangla for 18 acts (others fall back to English, flagged on screen) | non-English wording authored by the team; native-speaker check pending. Bangla interface chrome falls back to English |
| Screens | every S# and B# screen of A2, plus settings and study mode | — |
| Both prototypes | A and B in one app, same layout grammar | shared code paths mean some visual differences of the Figma versions were unified |

## Vertical (depth)

| Slice | Depth reached |
|---|---|
| **Price & bargain (A)** | real fragment assembly `[address][softener][price][hedge]`, register-labelled chips, firmer softener pools on 2nd/3rd counter-offers, no repeated fragment within a conversation |
| **Verifier (B)** | all four checks run for real on every sentence: placeholder integrity + stray digits; register classifier; round-trip by re-reading the output; confidence threshold 0.55. 14 automated tests |
| **Numbers** | slot extraction across 4 digit scripts, number words in 5 languages, unit inference; ambiguity handled (Hindi *दो* = "two" or "give") |
| **Seller loop** | seller can tap or speak; his speech is recognised in his language; long answers with no number are refused honestly |

## What is simulated, and why

| Proposal component | Prototype stand-in | Why |
|---|---|---|
| Quantised on-device NMT (120–180 MB) | domain-restricted clause generator with the same contract (masked input + register token → output with placeholders); optional Gemini cloud stand-in | no browser-deployable Indic NMT at this size; the verifier, not the translator, is the contribution under test |
| Silent degradation of compressed models | **compression simulator**: politeness leak, dropped clause, rewritten number, low confidence at 0 / 4 / 12 / 25 % for 16/8/4/3-bit | lets the verifier be exercised by real faulty outputs instead of a flag |
| Intent classifier (< 45 MB) | lexicon-based act recogniser | transparent and offline; same outputs (act, number, confidence) |
| Fine-tuned 3-register TTS | device TTS with register prosody (rate/pitch) | no custom voice; prosody approximates respectful vs familiar |
| On-device ASR | Web Speech API, `processLocally` when Chrome supports it | otherwise may use the browser's server; typing is the offline fallback |
| Wizard-of-Oz buttons of the Figma version | kept as dashed **TEST ONLY** controls and a facilitator panel | lets a facilitator force each branch reproducibly during evaluation |
| Pack size / latency | shown as the proposal's targets | not measured on a phone |

## What we deliberately did *not* compromise

- Nothing is ever spoken without a preview or a deliberate tap.
- A number is never generated by the language path.
- No swipe, drag or long-press anywhere; tap targets ≥ 48 px.
- Every state is carried by at least two channels.
